Labs

Learn by building

Six labs take you from a first MCP server to a production-grade enterprise support agent. Every lab ships with objective, prerequisites, architecture notes, starter code, expected output, and a validation checklist. Build first, read second.
  1. Lab 1~60 min

    Build your first MCP server

    Stand up a working Model Context Protocol server in TypeScript that exposes a customer-lookup tool and a compliant resource, connect it to an MCP client, and observe how tool schemas, descriptions, and structured errors drive Claude's behavior.

    D2 · Tool Design & MCP IntegrationD1 · Agentic Architecture & Orchestration
  2. Lab 2~75 min

    Structured-output extraction pipeline

    Build a production-grade invoice-to-JSON pipeline using tool-forced structured outputs, schema-honest nullability, validator-informed retries, and a golden eval set that catches regressions before they reach users.

    D4 · Prompt Engineering & Structured OutputD2 · Tool Design & MCP Integration
  3. Lab 3~60 min

    Tool-use agent loop from scratch

    Implement the core agentic loop by hand — tools, tool_result wiring, stop conditions, and budgets — so you can diagnose the failure modes (orphaned results, runaway loops) that frameworks normally hide.

    D1 · Agentic Architecture & OrchestrationD2 · Tool Design & MCP Integration
  4. Lab 4~90 min

    Orchestrator + subagent research system

    Build a three-agent research system — one orchestrator, parallel researcher subagents, one writer — practicing scoped briefs, fan-out/fan-in, and findings-with-provenance handoffs instead of transcript dumps.

    D1 · Agentic Architecture & Orchestration
  5. Lab 5~75 min

    Claude Code team workflow lab

    Configure a repository for serious Claude Code work: hierarchical CLAUDE.md memory, a custom slash command producing schema-validated JSON in headless CI, PostToolUse normalization hooks, and permission deny rules — programmatic enforcement instead of prompt-based hope.

    D3 · Claude Code Configuration & Workflows
  6. Lab 6~120 minCapstone

    Capstone: enterprise support agent

    Assemble everything — guarded tools, approval queues, typed errors, checkpoint summarization, and tracing — into one support agent that survives long sessions, provider outages, and compliance review.

    D1 · Agentic Architecture & OrchestrationD5 · Context Management & ReliabilityD4 · Prompt Engineering & Structured Output

Recommended order: MCP server → tool-use loop → structured outputs → Claude Code workflow → multi-agent research → capstone. Each lab’s validation checklist tells you when it is genuinely done.
