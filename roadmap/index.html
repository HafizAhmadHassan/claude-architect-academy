Week-by-week themes

  1. W1Foundations & diagnostic baseline — Take the diagnostic, set your target date, and skim the official exam guide.
  2. W2Agentic loop fundamentals — Trace a tool-use loop end-to-end and implement turn budgets.
  3. W3Orchestration & subagents — Build an orchestrator with two scoped subagents and explicit context handoffs.
  4. W4Tool design principles — Rewrite three tool descriptions against the contract checklist.
  5. W5MCP servers & clients — Ship the MCP server lab and connect it to Claude Code.
  6. W6Claude Code configuration — Author CLAUDE.md, custom commands, and permission rules for a real repo.
  7. W7Hooks, plan mode & CI automation — Automate a review pipeline with hooks and JSON output flags.
  8. W8Prompting & structured output — Build a validated extraction pipeline with schema-guided retries.
  9. W9Context management & reliability — Add checkpoint summarization and escalation routing to a long-running agent.
  10. W10Mock exam & weak-area repair — Sit the mock exam, drill your two weakest domains, and re-review missed scenarios.
